# 本地缓存试算与网络排查（2026-11-09）

Python 环境变量中没有 proxy 变量，但 urllib 系统代理配置返回 127.0.0.1:7897；沙箱内使用该代理报 WinError 10013。绕过代理（requests.Session.trust_env=False）对 Stooq、Yahoo 和 SEC 分别测试，均在 DNS 解析失败；不能断言外网服务故障。沙箱外直连测试未返回可核验结果。未修改代理或安全设置。SEC_USER_AGENT 未配置，尚待真实联系人；不得使用示例邮箱。SEC 正式数据接口尚未获取。

检查发现 stock_research/mature_tech_v1/prices 有 220 个 JSON，原始采集脚本 mature_prices.py 记载 AKShare stock_us_hist、adjust=qfq，起始 2020-03-01。按本地数据扫描，截止 2025-12-31 有 23 个证券至少一个五年窗口的收盘峰值达到十倍，见 local_candidates.csv；窗口采用月历月末恰逢交易日，选择每证券第一个符合条件窗口，不是全体月末，不是全市场或代表性样本。脚本 scan_local.py 可复现。2020 年起的数据不能支持完整十年窗口。数据为单来源前复权报价，无法确认分红再投资、公司行动和历史标识准确性，因此这些仅是待核查线索，不是已核验总回报案例。

例如 ANET 2020-03-31 至 2025-03-31 收盘比 6.121 倍，期间收盘峰值 10.255 倍；ENPH 相同窗口终点 1.922 倍、峰值 10.406 倍。两例说明按该缓存的价格序列，期间触及与终点判定可以不同，不构成市场规律。DBD 等涉及重组的证券尤其需要公司行动及证券连续性核验，价格拼接不能直接认定投资回报。

2025 Q1 的 SEC 本地批量文件不能提供 2020 起点前可用财报；未发现足够的起点前披露、股数和估值证据来完成十家公司。下一步：提供真实 SEC 联系邮箱并恢复允许的网络访问；对候选以独立行情和原始 10-K 核实日期、披露时间、财务数字与股份数，核对拆股、分红、重组后再升级为案例。仅有五年数据的证券十年项应保持未知。
