# 免费数据可行性结论与最小验证方案

结论（2026-11-11）：当前已实际获取的免费数据**不足以开展包含退市企业的完整历史市场十倍股识别**。可继续做有清晰来源和质量标记的个案方法试验，但不能报告全市场发生率或以现有样本代表失败企业。并非证明所有免费资源都不可能满足需求；目前没有经过测试证明合格的免费历史证券主表、公司行动和退市总回报链。

## 可复现覆盖测试

运行 `python tenbagger_research/feasibility_test.py` 和 `python tenbagger_research/coverage_cohort_test.py`。2020Q1 的 SEC ZIP 中，2020-03-31 前提交 10-K 的不同 CIK 计 4,014；与工作区现存 ticker 映射连接后 2,467 个有代码，1,547 未匹配，185 个 CIK 对应本地已保存行情文件。**这是申报主体和本地缓存覆盖测试，不是上市普通股总体、退市数量或全市场覆盖率**：申报主体包含非目标证券，映射日期、历史有效性和多股类均未知；行情文件是既有筛选生成的子集。20 家选定样本的 Yahoo 数据均有窗口两端，但正式总回报和标签通过核验为 0/20；20 家有年报及收入、经营现金流的结构化字段，字段和历史代码仍需原文审核。此次 20 家不是随机样本，不能外推覆盖率。

云端实测 Yahoo ANET 五年窗口三次成功、AKShare 三次成功，Stooq 同一测试三次 404；Yahoo 对 LEHMQ、SIVB 两个退市代码均 404。见 cloud_results_42953671168/results.json 和 cohort_raw；仅两只失败探针不能估计退市覆盖率。CLRO、BELFA 两源存在大额差异，已单独审计。Yahoo 的成功不证明股票池或分红/并购全事件完整；AKShare 的 qfq 价格不能默认相除得到含分红持有收益。退市后的终值（现金、换股、破产回收及时间）缺少可追溯记录；无法分辨缺失、退市、代码变更或零回收。

SEC 的免费季度结构化数据支持 accession、披露时间和 as-filed 的部分特征，2020 实测可处理；官方数据自 2009 年起，早期稀疏，2000—2008 年要用 EDGAR 原始报告或其他源，不能回填后报或重述。财务申报 CIK 非证券 ID、也非完整时点交易所股票池。https://www.sec.gov/dera/data/financial-statement-data-sets.html 。Nasdaq Daily List 的历史公司行动可回到 1999，但官方列为订阅产品而且仅 Nasdaq；https://www.nasdaqtrader.com/Trader.aspx?id=dailylistpd 。

## 补充资源与替代路径

优先请求学术机构核实 WRDS 的 CRSP 日/月回报、历史证券及退市、CRSP-Compustat 链接，以及真正 point-in-time 财务订阅；账户存在并不等同这些数据有授权。CRSP 描述含退市记录，具体版本、缺失退市收益和使用/再发布权仍需验证：https://www.crsp.org/research/crsp-us-stock-databases-2025-layout/ 。商业替代是审查 Sharadar 主类股票、价格及公司行动的许可证、历史映射、退市回收与缺失，官方价格历史自 1997-12-31，https://sharadar.com/prices 和 https://sharadar.com/docs/actions 。都尚未实测用户授权，不能把厂商宣传当作验收结果。免费替代只能做限定来源和可核验证券的探索性案例或明确范围的人工重建，不可宣称全市场或无幸存者偏差。

## 获得合格数据后的最小完整历史验证

1. 选单一同期起点 2015-12-31、五年终点 2020-12-31，覆盖主要美国交易所当日全部合格普通股，使用永久证券 ID 及有效日期映射；预先定义 ADR、双股类、上市转板。SEC 的当时申报按披露/接受时点连接，取不晚于起点收盘可得的版本；映射及财报缺失不删除证券，单独标记。
2. 获取每股持有期总回报（分红再投资，按来源明确再投资日），逐日或逐月按完整收益链累计；对拆股、股票/现金并购、分拆和退市按数据源定义处理，确认退市所得之后的持有规则并报告影响。起点指数 1，五年终点累计指数至少 10 才为终点十倍；停牌、退市缺失收益一律未知而非零或失败，现金退出后收益假设需预先固定并做敏感性分析。终点期间触及为另一个指标，不混用。
3. 固定数据提取版本、许可、完整分母及排除表；按年份、交易所、上市状态报告缺失，抽验上市、破产、现金收购、股票换股、分拆和代码变更。用公告及原始报告交叉核对，记录不一致及不可重建数量；若无法约束退市结局缺失，不作总体结论。
4. 在无未来信息前提下提取营业收入、增长、利润、现金流和已披露的股数/估值；按披露时间及证券有效链接，缺失保留。汇报五年终点十倍数量和分母，并分层描述起点特征与同期非十倍组；明确幸存者偏差、未知结局和右删失，进行缺失及并购处理敏感性分析。后续扩至 2000—2025 时，需按终点可观察性处理截止日期，非所有起点都具完整五年窗口。
