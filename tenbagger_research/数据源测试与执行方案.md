## 来源比较

| 来源 | 年份与能力 | 缺口和状态 |
|---|---|---|
| SEC submissions / companyfacts | 免费，无 API key；申报历史、XBRL facts，见 https://www.sec.gov/search-filings/edgar-application-programming-interfaces | 接口未成功实测；按 accession 和 filed/acceptance 选择起点前可用版本；公司扩展标签、修订、财报重述、财年和季度合成须核对原文。CIK 非证券永久 ID，不能当历史股票池或行情。 |
| SEC Financial Statement Data Sets | 官方季度 ZIP 自 2009 年起；https://www.sec.gov/dera/data/financial-statement-data-sets.html | 早期覆盖不完整，2000—2008 需原始 EDGAR 申报或商业历史数据；官方也声明提取值非原始申报替代。未下载实测。 |
| Stooq | 免费个股日线候选 | 请求因代理失败；起始年、退市覆盖、复权和分红再投资口径均未验证，不可用作全市场分母或声称总回报。 |
| Sharadar SF1 / prices / actions | 官方称 SF1 自 1998、含活跃和退市主体，as-reported 维度；价格文档称涵盖拆股、分红、分拆、并购和退市原因。https://sharadar.com/docs/fundamentals 和 https://sharadar.com/prices | 商业授权；官方称 99% 无幸存者偏差不是完整保证；需合同确认历史版本、再分发、退市现金及换股处理，实际账号和数据未验证。 |
| WRDS / CRSP + Compustat | CRSP 历史价格、收益、公司行动与退市信息；WRDS 描述链接 https://wrds-www.wharton.upenn.edu/documents/1452/CRSP_Data_on_WRDS.pdf | 需要所属机构 WRDS 账户及具体 CRSP、Compustat、所需 point-in-time 产品订阅；WRDS 账户本身不保证每个库有授权。见 https://wrds-www.wharton.upenn.edu/pages/about/wrds-account-types/ 和 https://wrds-www.wharton.upenn.edu/users/tou/ 。未验证用户机构权限，不收集账户凭据。CRSP 退市收益仍可能缺失，合并方式须按实际版本文档确认；数据导出和公开受许可证约束。 |

## 可执行路线

1. 免费案例路线：配置真实 SEC_USER_AGENT 后运行 `python tenbagger_research/test_sources.py`；修复代理连接并核查返回数据。逐个挑选有独立可追溯日线和公司行动的案例，保存原始来源和抓取日期；按同一收益口径算 5/10 年终点和每日收盘峰值。对起点之前最近披露的 SEC 10-K/10-Q 用 accession、接受时间、报表期和财务概念核对，估值用同日股数与价格；早期 XBRL 缺失回查原始申报。每个案例必须交叉验证拆股及现金分红，证据不足就记未知。案例是方便样本，不能推断总体频率或规律。
2. 完整市场路线：询问机构图书馆是否订阅 CRSP 日频、退市/分配、历史证券信息、CRSP-Compustat 链接和 point-in-time 财报；或取得 Sharadar 授权样本。先按年份核对上市和退市数，抽查破产、现金并购、换股、分拆及缺失退市收益；检验永久 ID 链接和历史行业。冻结授权数据版本与审计日志后再计算四项结果及含失败公司的同期对照。
3. 输出质量门槛：报告每年样本数、退市及缺失比例、不可确定的公司行动、特征缺失和右删失，敏感性分析退市收益缺失。公开产物仅保存许可证允许的统计、引用与代码。
