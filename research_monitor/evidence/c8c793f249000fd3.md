# NTRA 长期建仓：初步结果

截至 2026-11-06 美股收盘。每个窗口以相同日期开盘为起点，立即买入或先买 BIL；回撤条件为当日复权收盘相对于含当日在内前 252 个交易日最高收盘低 10%、20%、30%，次日开盘由 BIL 换入股票，持有至评价终点，未成交则全程持有 BIL。每笔交易成本 0.1%，BIL 与股票切换计卖买两笔；不计终点卖出费用与税。起点不将此前回撤当作已成交，第一天收盘已达条件则下一日买入。评价期内净值年化包括等待时间，日收盘最大回撤含等待期。无强制建仓，未成交不剔除。

滚动五年：每个满足 252 个历史交易日预热的交易日起点，共 1349 个高度重叠窗口。立即/10%/20%/30% 平均年化分别 31.63% / 30.66% / 30.99% / 33.04%；平均最大回撤 -75.47% / -75.44% / -75.01% / -74.91%；等待成功窗口的平均日历日 0 / 16.96 / 62.69 / 92.94；该样本内建仓成功率均 100%。不能将这些重叠窗口当独立试验；30%领先可能来自特定起点，未证明未来成立。

价格核验：Natera 年报确认从未支付现金股息；供应商 Yahoo 收盘与独立网页 2021、2022 年收盘 93.39、40.17 美元及 2026-11-06 收盘 310.67 美元一致。供应商没有上市后拆股事件，第三方显示未拆股；2016 年报提到 IPO 前反向拆股，不能误写为上市后事件。独立来源只核对若干锚点，不是完整逐日核验。[年报](https://www.sec.gov/Archives/edgar/data/1604821/000110465926020881/ntra-20251231x10k.htm)、[年线](https://us.kabutan.jp/stocks/NTRA/historical_prices/yearly)、[上市前拆股](https://www.annualreports.com/HostedData/AnnualReportArchive/n/NASDAQ_NTRA_2016.pdf)。Stooq 返回验证页面而非行情，保存为失败样本，不作为数据。
