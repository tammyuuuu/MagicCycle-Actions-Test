# 美股历史十倍股研究：数据审计与研究方案

状态：数据能力审计未通过；尚未开展全样本统计。审计日期：2026-11-09。

## 审计结论

当前工作区未发现覆盖 2000—2025 年美国上市证券、包含退市证券的完整历史证券主表或可核验的逐日复权行情库。`data_cache` 未列出文件；现有 `stock_research` 包含个别研究和有限批次数据，不能证明覆盖全部退市证券、历史成分或当时披露的财报。现有 Python 依赖包含 pandas、numpy、requests 和 akshare，但库本身不是历史覆盖或公司行动处理能力的证据。未接入或验证 CRSP、Compustat Point-in-Time 等数据库权限。

| 能力 | 结果 | 研究影响 |
|---|---|---|
| 历史证券主表与退市 | 未证明 | 无法建立无幸存者偏差的同期对照组 |
| 每日总回报与退市收益 | 未证明 | 无法准确判定终点和期间触及十倍 |
| 拆股、分红、合并、换股、分拆 | 未证明 | 无法保证跨公司行动收益可比 |
| 财报披露时间与历史版本 | 未证明 | 无法防止未来信息泄漏和事后修订偏差 |
| 历史流通股数、估值、行业 | 未证明 | 无法计算起点特征和可靠分层 |

因此案例库和对照组当前仅提供结构，不填入未经验证的案例，不推断十倍股规律或发生率。公开网站上可找到的幸存公司案例不能替代退市覆盖审计。

## 研究定义（待数据验证）

- 范围：美国交易所上市普通股，使用永久证券及公司标识；明确 ADR、基金、SPAC、不同股权类别和 OTC 的纳入规则，并保留排除记录。起点为 2000-01-01 至 2025-12-31 的交易日；每月末取一次起点以控制计算量，同一证券的窗口并非独立观测。
- 5 年、10 年终点：以起点之后对应日或其后首个交易日为终点；2025-12-31 为观察截止。终点复权总回报指数 / 起点指数 ≥ 10 判定终点十倍；期间触及以起点后至终点的日收盘总回报指数最大值 / 起点指数 ≥ 10 判定。日收盘不能识别盘中触及。两者分别记录，触及不意味着终点仍达标。
- 右删失：截止日前尚未走完期限的窗口不计入对应期限分母，也不标记为失败；例如 2021 年起点的 10 年终点不可观察。若先退市，按照数据源的退市收益和公司行动处理，不能直接当作价格为零或忽略；不能构造可靠持有回报的记录标为未知并报告数量。
- 比较基准：同一起点时可投资的全部合格证券，包括之后退市与失败者。比较十倍窗口与非十倍窗口，并单独展示退市、破产及未知结局；按起始年份和行业分层，必要时另做市值匹配。报告样本数、分母、缺失、置信区间，并以公司和时间聚类处理重复窗口。
- 特征：起点前可获得的市值、收入及增长、利润率、ROIC、经营现金流和自由现金流、估值及当时行业。财报使用实际首次公开时间，起点之前可得的信息；缺失披露日期时不以财政期末替代。股份数与价格日期一致；负利润估值单独标记，不强制计算负 PE。
- 复权：优先采用可追溯的总回报序列，记录分红再投资假设；对拆股、现金/股票并购、分拆和退市分别验证并保存事件与来源。证券价格复权因子不能自动视为覆盖全部公司行动。对比价格回报作为敏感性分析。

## 执行门槛与下一步

取得带授权的数据后，先按年份和交易所核对上市/退市数量及缺失率，抽查破产、现金并购、换股、拆股、分红和分拆，核对复权链及退市收益；核对财报披露日期与修订版本，并报告不可重建比例。通过后冻结数据版本、查询日期、样本规则和排除清单，再计算四类结果及同期对照。源表、代码、结果和审计日志应可复现。不得将完整窗口与删失窗口混作分母。

## 初步规律与限制

目前没有经过本研究样本验证的初步规律。任何关于小市值、高增长或行业集中度的说法都只是待检验假设，不能作为本研究发现。2000—2025 年的完整十年窗口最晚只能从 2015 年附近开始，具体取决于交易日；截面和窗口重叠也限制因果解释。结果是历史关联，不是投资建议或对未来收益的保证。
