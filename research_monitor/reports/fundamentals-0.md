# 基本面恶化后暂停新增：时间顺序复核

## 结论

截至2026-11-06，四家公司均**不启用自动“等待”条件**，维持买入并长期持有的既有基准。NVDA覆盖不足、MSFT测试期零触发，无法检验有效性；GOOGL唯一测试事件的暂停收益较低；BWXT测试期暂停略优，但只来自两次间隔不足半年且窗口重叠的触发，训练段相反，不能认定稳定。竞争优势、监管和公司特有风险仍需人工核查，不因本次未发现可靠自动规则而忽略。

## 规则和时间顺序

沿用上一轮事先写出的单一探索规则，不根据测试结果选择参数：披露时点可得的TTM收入同比为负、TTM营业利润率同比下降超过5个百分点、或TTM经营现金流减资本开支为负，任一满足即暂停新增；三项全部恢复时解除。只有SEC 10-Q/10-K及修订件实际申报日及以前的记录参与重建；申报当天不交易，最早下一交易日开盘执行。无有效数据或财报期末距交易日超过190天时视为未知，**不将未知视作未恶化**，事件窗口内任何一天未知即不出收益结果。

训练期2015—2020，时间顺序测试期2021—2026。该阈值在本次复核前已有报告，但对这些历史结果和分段此前已有了解；因此这只是按时间顺序冻结规则的历史重放，**不是事先注册、未曾接触数据的真正独立样本外验证**。没有调参或声称前瞻实盘检验。测试段里的1—3年窗口只在终点不晚于2026-11-06时统计；相邻事件窗口可重叠。

事件比较采用同一假设：触发日开盘已有股票仓位价值为每月投入额的12倍，之后每月第一个交易日投入1单位。始终买入组每月购股；暂停组已有股票始终持有，新增资金暂投BIL，恢复后合并买入。BIL及股票每腿0.1%成本，复权近似股息再投。以下是资金加权年化IRR，不是一次性持有CAGR，也不代表个人持仓；累计收益和订单数见 event_windows.csv。1、2、3年列为同一次事件的重叠窗口，不是独立试验。

|---|---:|---:|---:|
|GOOGL 2019-05-01，训练|11.00% / 9.15%|48.16% / 47.23%|23.77% / 23.29%|
|GOOGL 2023-04-27，测试|57.23% / 52.98%|16.92% / 15.54%|52.28% / 51.33%|
|BWXT 2018-11-07，训练|25.32% / 20.15%|3.48% / 1.77%|0.58% / -0.37%|
|BWXT 2021-02-23，测试|-23.87% / -21.23%|6.18% / 7.51%|25.15% / 25.96%|

BWXT两个测试事件相隔161天，三个期限均大幅重叠，可能受同一行业和市场阶段影响，不能当两次独立经济冲击。去掉任一事件后仅剩另一次，无法建立稳健的事件剔除结论；训练期唯一完整事件的三个窗口全部不利于暂停。GOOGL去掉唯一测试事件便没有测试证据。MSFT 2012-07-27有一个完整1年事件：始终11.37%、暂停6.20%，不在2015起的训练范围内，不能当作测试证据；NVDA没有覆盖完整且可评估的事件。

## 长期结果与覆盖

仅对整个分段每天均有有效财报状态的区间报告长期资金加权年化，使用同样的12单位初始仓位和每月1单位投入；样本不完整的分段不强行计算。2021-01-04—2026-11-06：MSFT 始终/暂停均16.33%，各72次股票订单且零触发；GOOGL 22.74%/22.60%，72/70次；BWXT 14.54%/14.95%，72/65次。订单包括初始购股。长期与事件IRR不能当作未来收益预期，且由投入假设影响。

2015—2020有效交易日覆盖：NVDA 0%、MSFT 39.05%、GOOGL 75.98%、BWXT 50.68%；2021—2026分别为41.18%、100%、100%、100%。NVDA测试期首个有效状态为2024-02-22，不能将缺失之前当作健康或无触发。覆盖率仅表示能够按脚本重建所需字段，不等于已完成财报口径逐笔审计。训练段、NVDA测试段因此未计算完整分段长期对照。

SEC标签映射、财年长度、重述和现金流资本支出口径尚需逐笔独立核对；NVIDIA生产资产支付近似资本开支。行情和BIL复权、拆股及股息也未完成第二数据源逐笔核对。数据、规则和脚本见 coverage.csv、event_windows.csv、long_run_complete.csv、pause_research.py；原始公司事实和行情由Cycle现有缓存只读提供。研究不能证明基本面指标无用，也不能证明本回放所见为可复制的预测能力。
